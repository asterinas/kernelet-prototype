# Kernelets on Linux

A kernelet is a kernel that runs inside Linux. It uses vOSTD for kernel services. The endovisor loads its image, and a host program creates and runs its sandbox.

[Why a kernel of your own](why-a-kernel-of-your-own.md) introduces the motivation and terminology. [The first kernel we will run](the-first-kernel-we-will-run.md) walks through the Hello World kernel and the services it needs.
